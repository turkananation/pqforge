# ADR-0003: X.509 certificates live in pqforge

## Status

Proposed with the 0.4.9 export. Accepted when that PR merges.

## Context

pqtransport needs to read an X.509 certificate when RawPublicKey was not
negotiated. The codec is not TLS. Other Dart projects need the same parse
and the same signature check without importing a transport.

0.4.8 already shipped `PqSymmetricPrimitives.chacha20`. This record is 0.4.9.

What already existed:

- ML-DSA-44/65/87 sign and verify, pure, empty context.
- `PqEcdsaP256`: signature, SHA-256, raw `r || s`, low-S.
- `p384SharedSecret`: ECDH for SecP384r1MLKEM1024. A 97-byte point in, a
  48-byte x-coordinate out. Not a signature.
- RSA and Ed25519 were not wrapped for a caller that needs a synchronous
  certificate check. Ed25519 in `package:cryptography` returns a `Future`.

## Decision

Export `PqX509` from `package:pqforge/pqforge.dart`. Source is
`lib/src/certificates/x509.dart`. The DER cursor is not exported.

`PqX509` parses one DER certificate, mints one, checks one signature, and
validates a path of at most 8 certificates against anchors the caller
passes in. It does not open a socket, write a TLS alert, read a trust
store, or fetch AIA, OCSP, or CT. `now` is an argument and must be UTC.

Public keys, serials, and signatures are `Uint8List`. A `BigInt` is built
only inside RSA, and only after the modulus is 2048, 3072, or 4096 bits
and the exponent is an odd integer in `3 .. 2^32-1`.

| Algorithm | Implementation |
| --- | --- |
| ML-DSA-44/65/87 | existing primitive, `preHash` false |
| ECDSA P-256 | existing `PqEcdsaP256` |
| ECDSA P-384 | new `PqEcdsaP384`. Same curve domain as the hybrid group. SHA-384. 96-byte `r \|\| s`. Do not call `p384SharedSecret`. |
| Ed25519 | new synchronous `PqEd25519`. 16-bit field limbs. RFC 8032, not HashEd25519. |
| RSA PKCS#1 and RSA-PSS | new `PqRsa`, PointyCastle, SHA-256/384/512 |

ML-DSA and Ed25519 take the TBS bytes as the message. ECDSA and RSA hash
inside the signer. Do not pre-hash those two.

A valid signature is not a trust decision. `validate` returns trusted only
when the chain links to a supplied anchor. A self-signed certificate is
trusted only when that certificate is one of the anchors.

## Consequences

- pqtransport consumes this export. It does not import `package:pointycastle`
  or `package:cryptography` to grow a second parser.
- No `.pqf` or `.pqfs` change.
- This is not a FIPS 140 module and not a WebPKI store.
